# Optimizer

A lightweight Windows 11 tool that runs in the background to optimize your PC for gaming.

## Features
- Pauses non-essential background services (temporary, resets on reboot)
- Safe temp file cleanup (won't delete files still in use)
- Network tweaks for lower latency
- Game Bar / Fullscreen Optimizations disabled for better gaming performance
- Lightweight 60 second background loop

## Requirements
- Admin rights (will prompt automatically)

## Notes
- All changes are safe and temporary — nothing is permanently modified
- Services and settings reset automatically after a reboot
